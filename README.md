# Smart Student Academic Planner
 
A simple website that helps students keep track of assignments, exams and daily study schedules in one place, so they never miss a deadline.
 
## Problem
Students often struggle to manage academic deadlines, assignments, exams and daily study routines effectively.
 
## Features
- **Dashboard:** a welcome message and a quick summary of pending work
- **Assignment tracker:** a form to add assignments and a table to view them
- **Exam schedule:** upcoming exams with date, time and topics
- **Weekly timetable:** a study plan from Monday to Friday
- **Study goals:** a checklist that crosses out finished goals
- **Quick notes:** a space for short reminders
- **Responsive design:** works on desktop, tablet and phone
## Built With
- HTML5 for the page structure
- CSS3 for styling, hover effects, transitions and media queries

## Limitations

- The "Add Assignment" button does not add rows yet (needs JavaScript)
